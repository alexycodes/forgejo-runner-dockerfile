# alexycodes/forgejo-runner

[![Docker Pulls](https://img.shields.io/docker/pulls/alexycodes/forgejo-runner?label=Docker%20Pulls&logo=docker)](https://hub.docker.com/r/alexycodes/forgejo-runner)

A [Forgejo Runner](https://code.forgejo.org/forgejo/-/packages/container/runner) image with extra tools:

- `curl`
- `jq`
- `openssh-client`
- `rclone`
- `rsync`
- `yq`
- `zstd`

Images are pushed to Docker Hub under [alexycodes/forgejo-runner](https://hub.docker.com/r/alexycodes/forgejo-runner).
